# Contributing

Thank you for your interest in contributing to `flp`!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/<your-username>/flp.git`
3. Create a branch: `git checkout -b fix-or-feature-name`

## Development

```sh
cargo check
cargo clippy --all-targets --all-features
cargo test
cargo fmt
```

All checks must pass before opening a pull request.

## Pull Request

- Keep changes focused and minimal
- Write clear commit messages
- Ensure tests pass
